Mutant Creatures Legacy (AGPL-3.0)

The mutant mobs, their items and their animations are a port of Mutant Creatures Legacy (mod id mutantbeasts) by ACGaming, IcarussOne and PessiMysterio (Elite Modding Team), a continuation of Mutant Creatures by shcott21/thehippomaster21 and the Mutant Beasts port by Chumbanotz, licensed under the GNU Affero General Public License v3. Our port is licensed the same way. Its complete source, including every change we made:

  • Server plugin (the mod's own code on a Forge compatibility layer): server/custom-plugins/JasprMutants
  • Browser client part (models, animations, particles, items): client-mods/mutants, built by scripts/build-mutants-client.cjs and scripts/build-mutants-pack.cjs
  • Build tools for the server plugin and how it was ported: scripts/build-mutants-plugin.sh, MUTANTS_PORT_NOTES.md, MUTANTS_PROTOCOL.md

  • Original mod: Mutant Creatures Legacy

The newer Mutant Skeleton sounds of the original mod are All Rights Reserved, so JasperCraft does not use them: it plays the mod's own older sounds (its legacy sound options), and vanilla sounds where no older sound exists.
